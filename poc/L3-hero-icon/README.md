# L3 角色立绘

本目录对应 `../hero-icon` 中的 68 张原始截图，成品与原图同名，方便逐张核对与替换。

- 规格：1024 × 1024，RGBA PNG，透明背景。
- 内容：45 张骑乘英雄，以及 23 张兵种、骑兵和攻城器械。
- 方向：保留原图的主要配色、发型、头饰、武器与骑乘关系，重新绘制为精致 Q 版立绘。
- 预览：用浏览器打开 `index.html`；点击图片查看原尺寸，切换明暗背景检查轮廓。`Review` 中为拼版预览，JPG 底色不是资源背景。
- 进度与逐图记录：`manifest.json`。只有 `all_delivered: true` 才表示所有输入已完成并通过文件规格检查。
- 文件校验：`verification.json`；目视检查与精修记录：`visual_review.json`。

使用内置 imagegen，逐张参考原始截图生成。统一尺寸时只做等比重采样和透明留边，保留生成图片的透明通道。原始截图未被覆盖；未改动 Unity 场景或脚本。

生成提示词与原始生成图保存在项目的 `work/hero_icons_20260922`：`jobs` 为逐图提示词，`source_art` 为生成原稿，`records` 为输出校验记录。
